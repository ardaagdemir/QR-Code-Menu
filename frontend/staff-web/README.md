# staff-web

QR Menü platformunun personel-yüzü web uygulaması (Next.js, TypeScript, App Router). İşletmenin bilgisayarında/
ekranında çalışması hedeflenir.

Kitchen Display Screen (KDS, canlı gelen siparişler - SSE, kalem/adet bazlı kabul-red), iade ekranı ve admin
ekranları (Şube/Masa/QR, Menü, Personel/Rol, Denetim Kaydı). Gerçek StaffUser e-posta/şifre girişi, cookie tabanlı
oturum (`qrmenu_staff_session`) ve rol/permission bazlı yetkilendirme (Milestone 8).

```bash
npm install
npm run dev
```

http://localhost:3002
