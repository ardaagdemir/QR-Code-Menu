# customer-web

QR Menü platformunun müşteri-yüzü web uygulaması (Next.js, TypeScript, App Router). Anonim ve mobil önceliklidir.

Milestone 1 kapsamı: yalnızca boot eden bir iskelet + placeholder ana sayfa. Menü, sepet, ödeme, QR akışı ve
authentication sonraki milestone'larda eklenir (bkz. [`docs/product-requirements.md`](../../docs/product-requirements.md)).

```bash
npm install
npm run dev
```

http://localhost:3000
